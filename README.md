# Pesquisa de Satisfação no Atendimento.
Projeto desenvolvido em Python com o objetivo de realizar uma pesquisa de opinião com clientes e identificar o grau de satisfação

### Objetivo

O programa coleta informações de 6 clientes, solicitando:

Nome;

Idade;

Opinião sobre o atendimento.

O cliente pode avaliar o atendimento utilizando uma das seguintes opções:

1 — Excelente

2 — Bom

3 — Ruim

Ao final da pesquisa, o programa apresenta a quantidade de respostas recebidas em cada categoria.

### Conceitos utilizados e Tecnologias

Neste projeto foram utilizados conceitos básicos da linguagem Python:

Variáveis;

Entrada de dados com input();

Conversão de dados com int();

Estrutura de repetição for;

Estruturas condicionais if, elif e else;

Contadores;

Saída de dados com print().

Python 3

Visual Studio Code

# Exemplo de utilização

Digite o seu nome: João

Digite a sua idade: 32

Digite sua opinião sobre o atendimento - 1: Excelente; 2: Bom; 3: Ruim: 1

Após a participação dos 6 clientes, um possível resultado seria:

### RESULTADO DA PESQUISA

Respostas Excelente: 3

Respostas Bom: 2

Respostas Ruim: 1
